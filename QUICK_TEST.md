# Quick Test Guide - UPDATED

## ⚠️ **CodeSandbox Doesn't Work**

CodeSandbox gives 502 errors because it can't handle backend+frontend apps.

---

## ✅ **USE THESE INSTEAD:**

### 🥇 **1. Replit (EASIEST - Actually Works!)**

1. **Go to**: https://replit.com
2. **Click**: "Create Repl" → "Import from GitHub"
3. **Paste**: Your GitHub repo URL
4. **Click**: "Run"
5. **Play!** 🎮

**Time:** 3 minutes | **Setup:** None!

---

### 🥈 **2. Deploy to Render (Best for Live Testing)**

1. **Go to**: https://dashboard.render.com
2. **Click**: "New +" → "Blueprint"
3. **Connect**: Your GitHub repo
4. **Click**: "Apply"
5. **Configure** environment variables (see DEPLOY.md)
6. **Done!** Live game at a real URL

**Time:** 10 minutes | **Cost:** Free

---

### 🥉 **3. Local One-Command**

**Mac/Linux:**
```bash
./quick-test.sh
```

**Windows:**
```bash
quick-test.bat
```

**Requirements:** Python 3.8+ and Node 16+

---

## 🎯 **Recommendation**

**Want it NOW?** → Use **Replit**

**Want it LIVE?** → Deploy to **Render**

**Have Python/Node?** → Run **quick-test.sh**
